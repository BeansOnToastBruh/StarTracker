StarTracker Windows build outputs
=================================

After `npm run dist`, shipping files are at the project root:

  StarTracker-<version>-x64.exe       NSIS installer
  StarTracker-<version>-portable.exe  Portable (no install)

Intermediate build output stays in dist/ (not for distribution):

  dist/win-unpacked/          Unpacked app directory
  dist/*.blockmap             Delta update blockmaps
  dist/builder-debug.yml      electron-builder debug log
  dist/builder-effective-config.yaml
